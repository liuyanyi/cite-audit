## 更新方式

1. 构建当前前端，在独立端口与新的数据目录启动服务，避免使用真实任务或已保存凭据的数据库。
2. 以演示模式上传 `docs/examples/demo.bib`，等待任务完成。
3. 截取任务概览；进入 BERT 详情，截取当前版本核验与来源证据区域。
4. 返回任务，打开“校订预览 / 导出”，选择“整体改用推荐版本”，进入预览后截取对话框。无需确认生成文件。
5. 检查文字清晰、内容完整、演示标记可见，更新本说明中的采集日期并复核 README 引用。保留来源失败、未决项和费用未知等真实提示，不修改截图中的判断或结果。
