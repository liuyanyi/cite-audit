# 实现与支持范围

## 模块

- `app/bibtex.py`：字符级状态机解析、语义摘要、单条建议生成，不执行 TeX。
- `app/audit.py`：确定性身份/字段/DOI/版本判断；每个事实性建议关联具体证据。
- `app/providers.py`：结构化来源、Search/Fetch、约束模型输出、mock。
- `app/security.py`：URL、DNS/IP、TLS 主机隔离、逐跳限制和脱敏。
- `app/storage.py`、`app/migrations/001_init.sql`：SQLite WAL、事务队列、上传快照和缓存。
- `app/worker.py`：单实例任务执行、预算、增量复查、结果版本。
- `app/locking.py`：POSIX flock / Windows msvcrt 单实例锁。
- `app/main.py`：FastAPI，页面和 JSON API；`/api/docs` 提供接口说明。
- `app/static/`：无构建依赖的原生 JS/CSS，文本节点渲染所有外部内容。

## 解析器

支持 brace/parenthesis 条目，嵌套和转义值、引号值、百分号注释、`@comment`、`@preamble`、前向 `@string`、`#` 拼接、标准月份宏、无歧义 crossref 继承。保留重复条目并报告重复 key/字段。损坏条目局部恢复，不静默丢掉后续可解析内容。

冲突宏、未定义/循环宏、循环 crossref、未支持的 BibLaTeX xdata 继承明确报告。原始 UTF-8 上传字节（包括 BOM/换行）按 BLOB 保存；展示用的解码文本独立保存。建议文件展开所需宏以使单条自包含，并保留已有 TeX 转义、中文、必要大小写保护及自定义字段。

解析器自身限制为 800 万字符、2 万条、128 层嵌套、单字段展开 100 万字符、全部展开/继承 1600 万字符以及约四倍输入长度的扫描预算；HTTP 层另收紧至 2 MiB/1000 条。

语义摘要排除 citation key、字段顺序和无关空白，包含所有语义字段和继承结果；歧义语法包含原文 hash。即使复用核验缓存，也重新针对新条目生成建议，不能带回旧 citation key。

## 证据与版本

来源记录在任务结果中按原始来源单独保存，不汇总成混合“超级记录”。请求缓存保存脱敏原响应；网页内容、来源元数据和抽取线索随证据记录保留；结果缓存引用相同证据快照。历史任务内嵌快照独立于可删除缓存。单实例串行队列和请求缓存合并等价查询，不需要 Redis。

记录带来源/获取时间/有效期/抽取方式/原始响应/来源链。搜索摘要、网页和模型抽取不等价于结构化书目。模型结果必须符合 schema、证据 ID 真实存在，值与已获取字段一致或出现在精确摘录中；输出仅为待人工核对线索，不自动执行或升级身份判断。

Crossref、DOI 内容协商或 DataCite 的同身份登记证据才能把 DOI 标为已核验。格式有效或聚合数据库给出 DOI 不足以证实登记及归属。请求失败与登记处无记录不同，Crossref 404 也不意味着其他 DOI 登记机构无记录。

正式版建议必须有显式版本关系、同一出版版本的完整必需字段及 DOI 登记依据。arXiv journal_ref/DOI、S2 同一记录的 external IDs、严格筛选的 Crossref/DataCite 关系保留具体类型与方向。引用/补充/扩展关系不自动视为可替换版本。建议整体更新版本字段并另存原 arXiv ID/版本及原文；用户仍需确认正文是否依赖预印本特有内容。

## 增量和错误

未变条目复用有效结果；修改过的标题/作者/年份等优先重新对照已有证据，能唯一确定身份时不联网。标识符变更到未知值时重新查证。启用 CNKI 只补该来源。规则/模型/端点/凭据版本进入配置摘要；原响应能继续复用，结论需要重新计算。代码变更时维护规则和适配器版本常量。

元数据/搜索/负结果 TTL 分层；核验结果期限取所有支持查询（包括负查询）的最早期限。未发现正式版等负状态进一步受 negative_days 限制。查询错误不进入负结果缓存。短重试有界，长 Retry-After 记录稍后可重试并停止本轮，不提前请求。预算耗尽保存已有证据，不虚构通过。

取消后当前请求可继续直到超时；之后不再发出新请求。进程重启恢复持久排队条目。进程崩溃恰在外部响应与本地提交之间时，重启可能重复那一次请求；不声称外部网络请求具备 exactly-once 语义。

## 手工题录

导入单条 UTF-8 BibTeX；RIS 支持 `TY/TI/T1/AU/A1/PY/Y1/JO/JF/JA/T2/VL/IS/SP/EP/DO/UR/SN/ET/PB/N2/ER`。续行或未知结构保留原文、报告支持边界，不声称兼容所有 CNKI 导出版本。字段文本支持 `title/标题/题名`、`author/作者`、`year/年份/出版年`、`journal/期刊/来源`、`doi`、卷期页码、出版社与 URL 的冒号分隔；自由文本/纯链接只作未核验线索。

人工导入不自动抓取链接，创建新的子任务并保留之前结果。人工记录无自动过期，始终标注“人工，未在线核验”。正式机构 CNKI 接口不在此版本中。

## 安全和运行

只绑定 loopback，校验 Host/Origin、禁止跨站写入，不启用开放 CORS。无账户系统，不能作为公网服务部署。数据目录本身需要用户账户级保护。

外发 URL 限 HTTP(S) 标准端口，无 URL 凭据，拒绝本地/私网/保留地址和混合 DNS；连接固定已验证 IP并保留正确 TLS SNI，TLS 池按原主机隔离。重定向重新检查目标、限制跳数并计入预算，跨主机移除鉴权。默认响应上限 2 MiB。API base URL 仅公开 HTTPS，故不支持直接把本地 LLM 服务地址填入。

后台参数、调用日志、缓存原响应和结果都在持久化前脱敏。改变凭据不会从旧缓存重新暴露旧 key。`.env` 不作为 shell 执行。正常日志不记录访问正文/密钥。设置保存是本地明文配置，不提供硬件加密或操作系统凭据库。

没有后台调度、公开部署、批量整库改写或第三方文件托管。依赖 API 的权威性与覆盖范围，不能将“无结果”当成不存在。
