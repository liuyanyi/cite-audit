# 语义核查字段 v1

字段规则修订：`semantic-fields-v1`。原始上传、来源快照不变；本规则用于新任务的评估，已完成报告不重新计算。

## 稳定含义与输入映射

| 核查含义 | Bib 字段 | 适用条件 |
| --- | --- | --- |
| 类型、标题、作者 | entrytype、title、author | 通用；类型仍需版本证据 |
| 编者 | editor | 书、章节、论文集及会议论文 |
| 出版年份、出版日期 | year、date | 分开保存比较，不把完整日期降为年份 |
| 在线首发日期 / 年份 | first_online_date、first_online_year | 与正式出版日期分开 |
| DOI | doi | 可选，必须核实所指对象 |
| 期刊 | journal / journaltitle | article |
| 收录书名 / 论文集 | booktitle | 会议论文、书籍章节 |
| 卷、期 | volume、number | 按类型；报告的 number 解释为报告编号 |
| 页码、文章号 | pages、articleno / eid / article-number | 两种独立定位语义 |
| 出版社、版次 | publisher、edition | 依类型适用；版次用于书和章节 |
| 报告机构、学位机构 | institution、school | 报告、学位论文分别适用 |
| 仓储标识、命名空间、分类 | eprint、archiveprefix / eprinttype、primaryclass / eprintclass | 分开比较；URL 不是版本主键 |
| 引用地址 | url | 仅核查来源提供的地址，不宣称链接已访问或永久有效 |

已确认 arXiv 版本不补入期刊、正式论文集、卷期、页码、文章号或出版社信息。未提供且来源也未提供的可选项不生成空白核查行；当前版本没有某字段的来源证据时仍为无法核实，不能因缺证据就判断错误。

## 别名与证据

一个语义项只产生一行结果。`semantic_key` 为稳定标识，`field` 保留实际用于修改的 Bib 字段名，`input_fields` 完整记录所有输入别名。原值之间存在冲突时不自动选择、不生成修正；来源别名冲突同样保持未决。可安全修正的同义输入字段同步产生建议，证据定位仍指向实际来源字段。

识别当前版本时可以使用无冲突的别名视图；这一视图不覆盖输入或来源事实。日期语义不相互推导，未知类型和未知字段不冒充已经支持的完整类型核查。

## 辅助字段与导出边界

未在目录中的字段通过 `auxiliary_fields` 单独返回，包含原值与未核查说明，例如 file、keywords、abstract、note、自定义字段、继承指令。它们不参与字段错误或补全数量，仍可在原始条目查看。

当前导出仍采用保留原字段的选择性修正，预览明确提示其中可能包含未经核查的信息；不把该模式称为“仅已验证字段”。本轮没有静默删除辅助字段。精简导出、单条复制/下载、所选条目导出需要下一步独立接入这些规则，并明确处理必要但未确认的字段。

报告的 `evidence_revision.field_rule_version` 冻结本次字段规则。已有报告按已有结果展示，不因新目录产生新的通过结论。
