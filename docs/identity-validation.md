# 候选筛选、姓名匹配与 achievements 回归

## 变更

规则版本为 `publication-identity-v2`。检索结果先做任务内相关性比较，明确无关的结果进入 `excluded_candidates`，保留来源内容与快照引用，不再参与身份歧义判断。相同 DOI/arXiv 的候选按标识符分组，保留每个来源记录。该分组只是展示层整理，不会归并共享出版版本。

标题规范化后的字符序列相似度低于 0.72 时排除；标题低于 0.95 且作者不符时也排除。其余记录仅是待核候选。分数不是置信度，不能单独确认身份。最终确认仍要求相容的 DOI/arXiv，或完整题名、作者、年份及会刊/页码组合。

只有多个出版版本实际通过身份判定才标记 `ambiguous`。有相关候选但不足以确认是 `insufficient`；全部候选排除且没有访问失败是 `not_found`；确有失败或限流而无法确认是 `source_failed`。未覆盖的来源能力与网络失败分开记录，专利明确提示当前来源不支持。

姓前姓后、空格、连字符及有逗号的姓名格式可用于完整作者序列比较。缩写、缺失作者或 `others` 不能充当完整姓名相同的证明。不同全名的同姓作者、署名顺序变化不会直接视为相同。来源把整组作者的 family/given 字段倒置时，要求至少两位完整姓名按同一署名顺序逐一对应；它可以佐证文章身份，但作者字段保留未核实状态，不自动输出猜测的逗号写法。arXiv 检索也不再固定猜测最后一个词是姓。

会刊比较兼容 `&`、`and`、HTML 实体、BibTeX 转义。它不采用任意会刊简称映射。错误 DOI 命中缓存时仍会继续发现；缺少输入所需字段的缓存不能直接结束核查。确认正式版后避免无必要的宽泛标题搜索，预印本仍保留正式版发现。仅扩展相关候选的官方链接，并对新发现 DOI 补查 Crossref。所有查询仍受原请求预算、来源开关和取消机制约束。

本轮未把 LLM 接入自动事实判定，也没有调用付费模型。实际姓名问题可由可回归的规则解决；仍缺少权威来源的条目不能用模型记忆补成已核实。

## 重现

完成的验证：后端完整测试 204 项通过；前端完整测试 48 项通过；TypeScript 类型检查、生产构建、wheel 构建及安装后从源码目录外执行的 CLI/API/资源/冻结报告/安全导出验证通过。`git diff --check` 通过。没有把截图当作交互验证，也没有调用付费 LLM。

```powershell
uv run --no-sync --locked python scripts/check_achievement.py
uv run --no-sync --locked python scripts/check_achievement.py --online
```

每次创建独立验证数据库。`--online` 才执行外部来源请求，复用后端来源配置，模型不参与。数据库路径与输出目录可用 `--database`、`--output` 指定。

旧任务的冻结报告不会被本轮规则自动改写。运行中的旧后端进程需要重新加载代码后，新任务才使用新规则；本次未停止或重启现有进程。
